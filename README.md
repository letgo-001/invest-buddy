# Invest Buddy

面向投资研究者的个人 Agent 工作台原型。它将 Agent Harness 的运行机制直接呈现在投资研究体验中：目标拆解、能力注册、计划执行、上下文压缩、长期记忆、检查点恢复、权限审批、证据溯源、故障降级、停止规则和运行观测。

## 在线产品

发布后访问 Sites URL。新站点默认仅创建者可见。

## 本地启动

这是一个零依赖静态应用：

```powershell
cd invest-buddy/dist
python -m http.server 4173
```

访问 `http://localhost:4173`。

## 核心体验

1. 打开研究线程，观察 Agent 计划和实时执行。
2. 点击计划卡片、证据引用和工具注册表查看 Harness 细节。
3. 运行会自动创建检查点；暂停后可继续，刷新后可从本地检查点恢复。
4. 数据源超时会显式标记为“待核”，展示重试与备用源策略，不进入结论。
5. 导出研究包或执行第 6 步时触发审批门，确认后生成研究产物。
6. 阶段结论区明确区分事实、信号和待验证反证，并附合规声明。

## 产品选择

- 用单一研究线程承载目标、任务、证据、产物与运行状态，减少研究者在多个工具间切换。
- 将 Agent Harness 可视化，但不暴露内部思维链；只展示计划、工具 I/O 摘要、状态、成本、时延和证据。
- 每个核心结论回链至来源、时点、单位、口径或原文字段。
- 默认只读工具自动运行；写入产物需要确认；交易能力明确禁用。
- 当前为交互式高保真原型，金融数据使用结构化模拟数据，避免将演示数据误当实时事实。

## 数据源与环境变量

产品集成设计优先支持：扶摇金融数据 API / MCP、iFinD MCP、公开网页检索。当前静态原型未连接真实接口，不需要环境变量。生产化建议仅在服务端配置：

```text
FUYAO_API_KEY=
IFIND_MCP_ENDPOINT=
MODEL_API_KEY=
```

禁止将密钥、用户持仓或受限数据提交到公开仓库。

## AI 使用与验证记录

- AI 参与：需求拆解、信息架构、交互与视觉设计、前端实现、边界场景枚举、测试设计。
- 人工需要复核：金融字段映射、数据供应商实际可用工具、估值口径、来源授权和所有对外研究结论。
- 已修正的典型风险：不输出确定性涨跌预测；数据超时不静默补值；信号不冒充事实；报告写入前增加审批；禁用交易工具；成本达到上限时停止。
- 验证方式：源码静态检查、浏览器交互检查、移动端响应式检查、站点发布状态检查。

## 测试说明

| 场景 | 操作 | 预期 |
|---|---|---|
| 主链路 | 等待任务推进并确认生成报告 | 6 步完成，进度 100%，研究包生成 |
| 暂停/恢复 | 点击暂停，再点击继续 | 状态保存；继续后从当前步骤运行 |
| 检查点 | 点击“从检查点恢复” | 显示上下文、记忆与证据已恢复 |
| 接口失败 | 查看碳酸锂证据 | 标记超时、重试和降级，不纳入结论 |
| 权限边界 | 点击导出研究包 | 出现 artifact.write 审批门 |
| 拒绝审批 | 点击“暂不生成” | 停留在审批点且状态保留 |
| 合规边界 | 检查阶段性判断 | 无收益承诺或直接买卖建议，有免责声明 |
| 证据验证 | 点击“查看原始字段” | 展示来源、时点、单位和字段口径 |
| 成本边界 | 查看“本次运行” | 展示预算使用及停止规则 |
| 响应式 | 以 390px 宽度访问 | 主内容单列，抽屉和审批弹窗可操作 |

## 已知边界与未做事项

- 当前用模拟数据完整演示产品主链路，尚未接入真实扶摇/iFinD 凭据。
- 尚未实现服务端多租户身份、加密持久化、真实模型编排和可重放的分布式 trace。
- 没有交易能力，也不会给出直接买卖建议。
- 生产版本应加入字段级数据契约、来源授权审计、模型评测集和人工发布复核。
